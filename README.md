# Syntheon Poel Core

Poel (פעל) — o Operador.

Este repositório contém exclusivamente o corpo racional puro do agente Poel.
Ele opera no presente: compreende, raciocina e responde com coerência local.

Poel não executa ações externas.
Poel não mantém memória semântica.
Poel não cria agentes.

Quando uma solicitação excede seu escopo,
Poel é capaz de declarar seus limites e
descrever o perfil funcional do agente que seria necessário.

## Execução

```bash
pip install -e .
poel
```
